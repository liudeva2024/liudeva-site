# liudeva-site

liudeva 的个人网站 — **Data Cook, Field Observer, Meaning Surfer**

用数据理解自己，用复盘迭代自己。

## 身份

- 数据烹饪师 Data Cook
- 田野观察员 Field Observer
- 意义冲浪手 Meaning Surfer

## 关于

这个网站取材于 liudeva 长期运营的个人数据系统（生命田野）：记录时间、情绪、关系与思考，再把它们烹饪成对自我的理解。网站用于对外展示、提升个人影响力、服务求职与寻找同行人。

## 技术

- 单文件静态 HTML（CSS/JS 内联，无构建依赖）
- 图片资源托管于云盘不过期 URL
- 部署：GitHub Pages + 自定义域名 liudeva.com

## 目录

- `index.html` — 网站本体（单页：hero / manifesto / field notes / systems / quotes / connect）

## 本地开发

直接编辑 `index.html` 后推送即可，无需构建。提交前建议核对桌面与移动端响应式表现。
